Bill Tracking System

Every medicine a doctor has written to a medical, down to the line. Switch “Show as” to roll the same rows up by doctor, by medical, by item, or by each doctor-and-medical pairing.

New medical (one time setup)

Medical directory

Click a row to open everything prescribed to that medical. Deleting a medical removes its prescription entries too. You will be asked to confirm.

New item

Anything saved here shows up in the item list on the bill form and the medicine list on the prescription form. A default rate fills itself into a bill row the moment you pick the item, and you can still change it on that row.

Item collection

Quantities and values count the date range above. Deleting an item takes it out of this list only — prescriptions already written keep their rows untouched. Any medicine name you type straight into a prescription is added here on its own.

New doctor

Doctor directory

Value prescribed counts every medicine line written by the doctor to any medical inside the date range. Deleting a doctor also deletes that doctor’s prescriptions and targets.

New prescription entry

₹0  total for this entry
One entry = one doctor, one medical, one date, and as many medicines as you want. Amount fills itself from qty × rate, and stays editable if you want to override it.

Prescriptions

New target

The target amount repeats every period. Periods run from your start date onward in blocks of the duration you set. Tick the box to carry every shortfall or surplus into the next period automatically, or leave it off and use the “Roll into next” button on any single period below.

Target tracking

Achieved = value of everything that doctor prescribed, across all medicals, inside the period dates. Carried in is what a previous period pushed forward: a positive figure raises this period’s target, a negative one is surplus credit and lowers it.

Software key and device

Key hidden
The key must be a software key issued by your administrator; it is checked against the licence server on activation and every 30 seconds after, so a revoked or expired key signs this device out on its own within moments. Only one device may hold that key at a time — this one keeps its claim alive automatically, and the claim lapses after 10 minutes of silence so another device can pick it up. Release it yourself when you are done for the day.

Auto-save to a data file

Download backup

File is named bts-backup-YYYY-MM-DD_HHMM.json — one file holding every medical, bill, deposit, doctor, prescription and target. This is a one-off copy; the auto-save file above updates on its own. PDF, PNG and CSV downloads sit at the bottom of each tab.

Load data from JSON

Pick one file or several at once — hold Ctrl (Windows) or Cmd (Mac) while clicking. All chosen files load together. Merge keeps what is already here and skips records already present; Replace clears everything first.

New bill

Parcel value is the goods value that deposits are set against. Bill amount is the billed entry. Enter jumps to the next field; Enter on the last field saves.

Bills

New deposit

Deposits are party-wise and reduce the parcel balance. Any deposit stays editable — hit ✎ on its row and change the amount or date until the parcel balance reads zero.

Party directory

Deleting a party removes all of its bills and deposits too. You will be asked to confirm.

New doctor

Doctor directory

Value prescribed counts every medicine line written by the doctor to any medical inside the date range. Deleting a doctor also deletes that doctor’s prescriptions and targets.

New prescription entry

One entry = one doctor, one medical, one date, and as many medicines as you want. Amount fills itself from qty × rate, and stays editable if you want to override it.

Prescriptions

New target

The target amount repeats every period. Periods run from your start date onward in blocks of the duration you set. Tick the box to carry every shortfall or surplus into the next period automatically, or leave it off and use the “Roll into next” button on any single period below.

Target tracking

Achieved = value of everything that doctor prescribed, across all medicals, inside the period dates. Carried in is what a previous period pushed forward: a positive figure raises this period’s target, a negative one is surplus credit and lowers it.

Download backup

File is named bts-backup-YYYY-MM-DD_HHMM.json — one file holding every party, bill and deposit. PDF, PNG and CSV downloads sit at the bottom of each tab.

Load data from JSON

Pick one file or several at once — hold Ctrl (Windows) or Cmd (Mac) while clicking. All chosen files load together. Merge keeps what is already here and skips records already present; Replace clears everything first.
